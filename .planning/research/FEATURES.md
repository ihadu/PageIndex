# Feature Research: 采购类型分类与政策性评分项

**Domain:** 中国政府采购 - 采购评分项知识库系统
**Researched:** 2026-04-17
**Confidence:** HIGH（基于财政部87号令、财库〔2020〕46号等法规文件）
**Mode:** Project Research（新增功能特征研究）

---

## Feature Landscape

### Table Stakes（用户期望功能）

政府采购评审专家和代理机构期望系统具备以下功能，缺失将导致产品不完整。

| Feature | Why Expected | Complexity | Notes |
|---------|--------------|------------|-------|
| **采购类型分类** | 财政部87号令明确规定货物类和服务类评分权重不同，评审时必须区分 | LOW | 顶层架构增加 `procurement_type` 参数 |
| **权重差异化配置** | 货物类价格权重30-50%，服务类价格权重10-30%，法定要求 | MEDIUM | 需重构知识库结构，按类型分权重 |
| **中小企业声明函识别** | 财库〔2020〕46号强制要求，所有政府采购项目必备政策性评分项 | LOW | 新增评分项类型，关键词识别 |

### Differentiators（差异化功能）

以下功能非必需，但能提升产品竞争力和用户满意度。

| Feature | Value Proposition | Complexity | Notes |
|---------|-------------------|------------|-------|
| **绿色产品认证检测** | 政府采购绿色产品优先采购政策加分，增值检索能力 | MEDIUM | 需关联品目清单，关键词库扩展 |
| **智能权重推荐** | 根据采购类型自动推荐评分项权重配置，减少用户配置负担 | MEDIUM | 需基于历史项目数据建模 |
| **政策性评分项自动更新** | 监测财政部公告，自动更新政策性加分关键词 | HIGH | 需政策监测机制，延迟实现 |

### Anti-Features（应避免功能）

以下功能常被用户请求，但会偏离系统定位或增加不可控风险。

| Feature | Why Requested | Why Problematic | Alternative |
|---------|---------------|-----------------|-------------|
| **自动评分计算** | 用户希望一键得出评分结果 | 评分需人工审核证明材料有效性，系统仅定位页码 | 仅提供页码定位，评分人工复核 |
| **证明材料有效性校验** | 用户希望自动检测证书过期、公章缺失 | OCR+日期解析复杂度高，政府采购合规风险大 | 人工复核有效性，系统仅提醒 |
| **工程类采购扩展** | 用户希望覆盖所有采购类型 | 工程类适用招标投标法而非政府采购法，规则差异大 | 明确系统边界，仅支持货物/服务 |

## Feature Dependencies

```
采购类型分类 (TYPE-01)
    └──requires──> 权重差异化配置 (TYPE-02)
                       └──enhances──> 评分项检索精度

中小企业声明函 (POLICY-01)
    └──requires──> 知识库结构扩展
                       └──conflicts──> 现有9种评分项扁平结构

绿色产品认证 (POLICY-02)
    └──requires──> 品目清单数据
                       └──conflicts──> 无品目清单数据库

评分项检索 ──enhances──> 政策性评分项识别
```

### Dependency Notes

- **采购类型分类 requires 权重差异化配置：** 87号令规定不同类型权重不同，分类后必须配置权重才有实际价值
- **权重差异化 enhances 评分项检索精度：** 高权重评分项关键词优先搜索，提升检索效率
- **中小企业声明函 conflicts 现有扁平结构：** 当前知识库9种评分项无层级分类，需重构为分层结构
- **绿色产品认证 conflicts 无品目清单数据库：** 绿色产品加分依赖财政部品目清单，系统无此数据

## 政府采购法规背景

### 采购类型分类法定依据

依据《政府采购货物和服务招标投标管理办法》（财政部令第87号）第五十五条：

| 采购类型 | 价格分权重范围 | 关键评分项 | 法规依据 |
|---------|--------------|-----------|---------|
| **货物类** | 30%-50% | 报价表、设备发票、质量证明、检测报告 | 87号令第55条 |
| **服务类** | 10%-30% | 报价表、人员配置、服务方案、业绩证明 | 87号令第55条 |

**货物类典型评分结构：**
```
价格（30-50分）├── 报价表
              ├── 分项报价表
              └── 价格偏离表

技术指标（20-40分）├── 技术参数表
                  ├── 检测报告
                  ├── 产品说明书
                  └── 样品

售后服务（5-15分）├── 服务承诺书
                 └── 售后网点证明

业绩（5-10分）├── 中标通知书
             ├── 合同
             └── 验收报告

资质（5-10分）├── 营业执照
             ├── 生产许可证
             └── ISO认证
```

**服务类典型评分结构：**
```
价格（10-30分）├── 报价表
              └── 费用明细

技术方案（20-40分）├── 服务方案
                  ├── 实施方案
                  ├── 技术响应
                  └── 质量保证

人员配备（10-25分）├── 人员名单
                  ├── 资质证书
                  ├── 培训证明
                  └── 健康证明

业绩（10-20分）├── 中标通知书
             ├── 合同
             └── 验收报告

资质（5-15分）├── 营业执照
             ├── 行业资质
             └── 认证证书

信誉（5-10分）├── 荣誉证书
             └── 信用证明
```

### 政策性评分项法定依据

依据《政府采购促进中小企业发展管理办法》（财库〔2020〕46号）第九条：

| 政策性评分项 | 适用条件 | 加分/扣除方式 | 证明材料 |
|------------|---------|--------------|---------|
| **中小企业声明函** | 小微企业提供本企业产品/服务 | 价格扣除6%-10%后参与评审 | 《中小企业声明函》（财政部格式） |
| **中型企业产品** | 中型企业提供小微企业产品 | 同小微企业价格扣除 | 《中小企业声明函》 |
| **联合体投标** | 小微企业份额≥30% | 价格扣除2%-3% | 联合体协议 + 《中小企业声明函》 |

**中小企业声明函检索特征：**
- 标题关键词：`中小企业声明函`、`中小企业声明`、`小微企业声明`
- 证明材料关键词：`从业人员`、`营业收入`、`资产总额`、`所属行业`
- 单页结构，无需扩展页

依据《关于调整节能产品政府采购清单和环境标志产品政府采购清单的通知》：

| 政策性评分项 | 适用条件 | 加分方式 | 证明材料 |
|------------|---------|--------------|---------|
| **绿色产品认证** | 产品列入节能/环境标志清单 | 评审加分（具体分值由采购人确定） | 认证证书、节能标志、环境标志 |
| **品目清单匹配** | 采购品目在清单范围内 | 优先采购或加分 | 产品认证文件 |

**绿色产品认证检索特征：**
- 标题关键词：`绿色产品认证`、`环保产品`、`节能产品`、`环境标志`
- 证明材料关键词：`节能认证`、`环境标志认证`、`绿色认证证书`、`中国环境标志`
- 需关联品目清单判断是否适用

## MVP Definition

### Launch With (v1.1)

v1.1里程碑最低实现：

- [x] **TYPE-01: 采购类型分类** — 顶层架构增加 `procurement_type: "goods" | "services"` 参数，评审时区分类型
- [x] **TYPE-02: 权重差异化配置** — 知识库按类型配置不同权重，货物类价格权重高，服务类人员权重高
- [x] **POLICY-01: 中小企业声明函识别** — 新增评分项类型，关键词识别，单页结构

### Add After Validation (v1.x)

验证核心功能后添加：

- [ ] **POLICY-02: 绿色产品认证检测** — 需关联品目清单数据，延后实现
- [ ] **智能权重推荐** — 基于历史项目数据建模，延后实现
- [ ] **政策性评分项自动更新** — 需政策监测机制，延后实现

### Future Consideration (v2+)

产品成熟后考虑：

- [ ] **地区知识库差异化** — 各省采购规则差异，需构建地区级知识库
- [ ] **证明材料有效性提醒** — OCR检测日期，提醒人工复核
- [ ] **评审结果辅助计算** — 仅辅助计算，不替代人工评分

|---------|------------|---------------------|----------|
| 采购类型分类 | HIGH（法定要求） | LOW（参数扩展） | P0 |

## Implementation Complexity Analysis

### TYPE-01: 采购类型分类

**实现方案：**
```python
# 知识库结构扩展
PROCUREMENT_REQUIREMENTS_KNOWLEDGE = {
    "metadata": {
        "procurement_type": "goods" | "services",  # 新增类型参数
        "version": "v1.1"
    },
    "requirements": {
        "报价响应": {
            "goods_weight": 30-50,  # 货物类权重
            "services_weight": 10-30,  # 服务类权重
            ...
        }
    }
}
```

**复杂度：LOW**
- 仅需在知识库顶层增加类型参数
- 不影响现有检索逻辑
- 用户需在初始化时指定类型

### TYPE-02: 权重差异化配置

**实现方案：**
```python
# 评分项配置扩展
"报价响应": {
    "category": "价格类",
    "weight_config": {
        "goods": {"min": 30, "max": 50, "recommended": 40},
        "services": {"min": 10, "max": 30, "recommended": 20}
    },
    ...
}

"人员配备": {
    "category": "人员类",
    "weight_config": {
        "goods": {"min": 0, "max": 10, "recommended": 5},  # 货物类人员权重低
        "services": {"min": 10, "max": 25, "recommended": 15}  # 服务类人员权重高
    },
    ...
}
```

**复杂度：MEDIUM**
- 需重构知识库结构，增加权重配置
- 检索时需根据类型调整关键词优先级
- 用户界面需显示权重配置

### POLICY-01: 中小企业声明函

**实现方案：**
```python
# 新增政策性评分项
"中小企业声明函": {
    "category": "政策类",
    "description": "中小企业认定声明函",
    "procurement_types": ["goods", "services"],  # 适用类型
    "title_keywords": [
        "中小企业声明函", "中小企业声明", "小微企业声明",
        "中型企业声明", "企业类型声明"
    ],
    "material_types": {
        "声明函": {
            "keywords": ["从业人员", "营业收入", "资产总额", "所属行业"],
            "description": "企业规模声明内容",
            "single_page": True  # 单页结构
        }
    },
    "policy_reference": "财库〔2020〕46号",
    "price_deduction": {
        "goods": {"min": 6, "max": 10},  # 货物类扣除6-10%
        "services": {"min": 6, "max": 10}  # 服务类扣除6-10%
    },
    "page_expansion_rule": {
        "direction": "none",  # 不扩展
        "max_pages": 1
    }
}
```

**复杂度：LOW**
- 仅需添加新评分项类型
- 关键词库扩展
- 不影响现有评分项

### POLICY-02: 绿色产品认证

**实现方案：**
```python
# 新增政策性评分项
"绿色产品认证": {
    "category": "政策类",
    "description": "节能/环境标志产品认证",
    "procurement_types": ["goods"],  # 仅适用货物类
    "title_keywords": [
        "绿色产品认证", "节能产品认证", "环境标志产品",
        "环保产品", "节能认证", "中国环境标志"
    ],
    "material_types": {
        "认证证书": {
            "keywords": ["节能认证证书", "环境标志证书", "绿色产品证书"],
            "description": "节能/环境标志认证证书"
        }
    },
    "policy_reference": "节能产品政府采购清单",
    "requires_catalog": True,  # 需关联品目清单
    "page_expansion_rule": {
        "direction": "forward",
        "max_pages": 3
    }
}
```

**复杂度：MEDIUM**
- 需关联品目清单数据
- 仅适用货物类采购
- 需判断采购品目是否在清单范围

## User Interaction Patterns

### 采购类型分类交互

**用户输入：**
```python
client = VisionPageIndexClient(
    procurement_type="services",  # 指定采购类型
    workspace="./workspace"
)
```

**系统响应：**
- 根据类型加载对应权重配置
- 服务类：人员配备关键词优先搜索
- 货物类：报价关键词优先搜索

**预期行为：**
- 类型参数影响检索优先级
- 权重配置影响关键词匹配权重
- 用户可查看当前类型权重配置

### 政策性评分项交互

**用户查询：**
```python
result = client.retrieve_with_expansion(doc_id, "中小企业声明函")
```

**系统响应：**
```json
{
    "requirement_type": "中小企业声明函",
    "category": "政策类",
    "page_ranges": ["45"],
    "title_pages": [45],
    "material_pages": [],
    "policy_info": {
        "price_deduction_range": "6%-10%",
        "policy_reference": "财库〔2020〕46号"
    }
}
```

**预期行为：**
- 自动识别政策性评分项
- 返回政策依据信息
- 单页结构，不扩展
