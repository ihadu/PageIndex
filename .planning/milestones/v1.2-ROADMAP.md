# Milestone v1.2: 证明材料页漏检修复

**Status:** ✅ SHIPPED 2026-04-18
**Phases:** 单阶段实现（非 Phase 模式）
**Total Plans:** 1 plan（直接实现）

## Overview

修复证明材料页漏检问题，实现连续性追踪、双向搜索、人员信息特征检测，解决合同条款页、业绩材料页数限制、证明材料在标题页之前等核心痛点。

## Shipped

### 核心功能

- **连续性追踪**: `_should_continue_material()` 方法追踪多页证明材料（合同条款页等）
- **关键词分层**: 强关键词单独触发 + 弱关键词追踪使用（`weak_keywords` 字段）
- **停止条件检测**: `get_all_title_keywords()` 遇到新评分项标题自动停止扫描
- **双向搜索**: `bidirectional` 模式支持向前搜索，`backward_pages` 参数配置向前扩展页数
- **人员信息特征检测**: `person_info_pattern` 配置检测多人列表（姓名、性别、出生日期等）
- **扩展范围增大**: `max_pages` 从 20 增加到 50，覆盖更长业绩材料

### 解决的具体问题

1. ✓ **合同条款页漏检** — 合同首页后有"条款"、"违约责任"等页面无首页关键词，现已追踪
2. ✓ **业绩材料页数限制** — 原 20 页限制不够，现增大到 50 页
3. ✓ **证明材料在标题页之前** — bidirectional 双向搜索支持向前扩展
4. ✓ **评分项标题误触发停止** — 上下文关键词检测，合同条款页中的评分项关键词不停止
